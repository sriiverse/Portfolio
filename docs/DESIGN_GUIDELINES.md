# DESIGN_GUIDELINES.md

> Project: **SRIIVERSEAI**
>
> Version: 1.0
>
> Purpose:
>
> Define the visual language, interaction principles, motion system, typography, spacing, and design standards for the SRIIVERSEAI portfolio.

---

# Design Philosophy

The portfolio should not resemble a traditional resume website.

Instead, it should feel like entering an AI operating system.

The visual identity should communicate:

- Intelligence
- Precision
- Engineering Excellence
- Modern AI
- Premium Software

The goal is to create an experience that recruiters remember long after leaving the website.

---

# Core Design Principles

## 1. Minimalism

Every element should have a purpose.

Avoid decorative components that do not contribute to usability or storytelling.

---

## 2. Functional Beauty

Visual appeal should emerge from thoughtful engineering rather than excessive ornamentation.

Animations, gradients, and effects must support content—not distract from it.

---

## 3. Consistency

Every page should share the same design language.

Maintain consistency across:

- Typography
- Buttons
- Cards
- Shadows
- Borders
- Motion
- Spacing
- Icons

---

## 4. Accessibility

Design decisions must prioritize usability for all visitors.

Ensure:

- WCAG AA color contrast
- Visible focus indicators
- Keyboard accessibility
- Reduced motion support
- Screen reader compatibility

---

# Visual Identity

The portfolio should evoke the aesthetic of:

- OpenAI
- Linear
- Stripe
- Apple
- Vercel
- Framer

Characteristics include:

- Dark, immersive interface
- Soft glassmorphism
- Subtle gradients
- Premium typography
- Restrained motion
- High readability

---

# Color System

## Primary Background

Deep charcoal or near-black.

Purpose:

Provide contrast for vibrant accents while reducing eye strain.

---

## Surface Colors

Use layered surfaces to establish hierarchy.

Example:

- Background
- Elevated cards
- Floating panels
- Dialogs
- Assistant workspace

---

## Accent Colors

Reserve accent colors for interactive elements only.

Examples:

- Buttons
- Active navigation
- Focus states
- Links
- Highlights

Avoid using accent colors for large backgrounds.

---

# Typography

## Primary Font

Modern geometric sans-serif.

Examples:

- Inter
- Geist
- SF Pro Display (system)

---

## Hierarchy

Use a clear hierarchy:

- Hero Title
- Section Title
- Card Title
- Body
- Caption

Avoid more than five text sizes.

---

## Line Length

Target:

60–80 characters per line for body text.

This improves readability.

---

# Spacing System

Adopt an 8px spacing grid.

Examples:

- 8px
- 16px
- 24px
- 32px
- 48px
- 64px

Consistent spacing produces visual rhythm.

---

# Components

## Buttons

Buttons should be:

- Rounded
- High contrast
- Keyboard accessible
- Clearly interactive

Hover:

Subtle elevation.

Active:

Small scale reduction.

---

## Cards

Cards should emphasize content through:

- Rounded corners
- Soft shadows
- Frosted glass surfaces
- Gentle hover animations

Avoid excessive blur.

---

## Navigation

Navigation should remain lightweight and unobtrusive.

Support:

- Sticky positioning
- Active section highlighting
- Smooth scrolling

---

# Motion Principles

Animation should communicate state changes rather than serve as decoration.

Use motion to indicate:

- Navigation
- Focus
- Expansion
- Loading
- Success

Avoid continuous looping animations that do not add value.

---

## Timing

Recommended durations:

- Hover: 150–200ms
- Button Press: 100–150ms
- Section Transition: 300–500ms
- Modal: 250–350ms

Maintain consistent easing.

---

# Three.js Guidelines

Three.js should enhance immersion without competing with content.

Guidelines:

- Maintain 60 FPS on capable devices.
- Reduce effects on low-end hardware.
- Pause rendering when inactive.
- Keep particle counts adaptive.

The scene should remain atmospheric rather than dominant.

---

# AI Assistant Design

The assistant should resemble a premium AI workspace.

Characteristics:

- Spacious layout
- Streaming responses
- Rich Markdown rendering
- Syntax-highlighted code
- Smooth scrolling
- Clear message hierarchy

The assistant should always feel like the centerpiece of the experience.

---

# Responsive Design

Support:

- Desktop
- Laptop
- Tablet
- Mobile

Prioritize:

- Readability
- Touch targets
- Simplified layouts
- Reduced animation on smaller devices

---

# Iconography

Use a single icon family throughout the project.

Icons should:

- Match stroke width
- Maintain consistent sizing
- Convey meaning immediately

---

# Imagery

Replace placeholder illustrations with authentic content:

- Real screenshots
- Architecture diagrams
- Project previews
- Workflow illustrations

Authenticity builds credibility.

---

# Future Evolution

As the portfolio grows:

- Expand design tokens.
- Introduce reusable component documentation.
- Maintain visual consistency.
- Avoid redesigns that compromise usability.

---

# Final Design Principles

The design should communicate confidence through restraint.

Visitors should leave with the impression that:

- The engineering is deliberate.
- The interface is polished.
- The AI assistant is genuinely useful.
- Every interaction reflects craftsmanship.
